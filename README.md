# Dr. S. Pawar's Homoeopathy — V6 Production Candidate

Responsive 10-page clinic website with Vercel serverless appointment enquiry email integration.

## Pages
Home, About, Dr. Sanjay W. Pawar, Dr. Sushant S. Pawar, Treatments, Patient Success Stories, Online Consultation, Clinics, FAQ, Contact.

## Deploy
See `VERCEL_DEPLOYMENT_GUIDE.md`. The project root includes `package.json` and `api/appointments.js` for Vercel. Add SMTP credentials as Vercel Environment Variables and redeploy.

## Important
This is a production candidate, not a live-verified deployment. The clinic must add its Gmail App Password in Vercel, connect its real domain, complete a live email test, verify Google Search Console/Business Profile, and manually confirm Google Meet appointments. No secret is included in this package.
